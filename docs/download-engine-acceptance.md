# 下载器能力保留与替代验收

记录日期：2026-10-22。评估对象：2.2.0-preview.1，源码 b29ff6a。

## 当前结论

不能保证专属内核全面不弱于 aria2，也没有完成 aria2 功能等价替代。
三端功能和故障测试通过，不等于同条件性能优于 aria2。现有真实源测试没有配对的 aria2 基线，不能用它宣称速度、成功率或资源占用优势。

用户要求保留 aria2 能力并增加生信优化。按完整能力目标评估时，应保留原版 aria2 内核，在任务调度、源识别、元数据校验、恢复诊断和界面层增加生信能力；专属 HTTP 内核只承担经过独立验证的场景。下列路线和验收标准是开发要求，不表示已经实现或测试通过。

## 能力差异

| 能力 | 原版 aria2 | 当前专属内核 / 客户端 |
|---|---|---|
| HTTP/HTTPS 分段、暂停、续传 | 支持 | 专属内核支持，已做三端故障测试 |
| FTP/SFTP | 支持，取决于构建功能 | 专属内核未实现；客户端仍调用 aria2/curl |
| BT、磁力链接、Metalink | 支持，取决于构建功能 | 专属内核未实现；当前客户端适配层不提供完整入口，并关闭自动跟随 torrent/metalink |
| 单文件多镜像/多协议来源 | 支持 | 专属内核当前固定单一来源；客户端尚未提供等价多源任务模型 |
| JSON-RPC / XML-RPC / WebSocket 控制 | 官方提供相应接口 | 专属内核没有 aria2 RPC 兼容接口；客户端也未开放完整原版 RPC |
| Cookie、认证、自定义请求头及高级参数 | 官方有相应选项 | 专属内核面向无内嵌凭据 HTTP(S) 直链，不能当作全部选项兼容；网页登录另走既有浏览器会话流程 |
| 缺少强 ETag 或不支持 Range 的源 | 原版可处理部分此类情况，续传能力取决于源 | 严格内核拒绝；仅在创建专属断点前允许兼容转用 aria2 |
| 官方分块摘要/全文摘要 | Metalink/BT 分块摘要，或 checksum 选项 | 专属块 SHA256 用于本地恢复，不是官方块摘要；产品全文 MD5 仍可选 |
| 磁盘与文件系统兼容 | 依实际版本和平台验证 | 专属内核要求支持硬链接发布；不足时只能在新任务尚无断点前使用兼容引擎 |
| 既有断点 | 原版识别自己的控制文件 | `.st`、`.aria2`、`.biodl-journal` 固定对应引擎，不跨格式拼接 |

本机包内 aria2c 1.37.0 的 `--version` 显示 BitTorrent、Metalink、XML-RPC、SFTP 等编译功能。该结果仅证明本机二进制报告这些能力，不能代替 Windows/Linux 构建探测或完整端到端验证。保留二进制也不等于客户端已经开放全部功能。

## 生信优化边界

- 保留可信来源的 ENA/NCBI 文件身份、大小和参考摘要，区分“传输完成”“快速检查通过”“全文摘要一致”。
- 保留可选全文 MD5、手动校验、已知摘要不一致文件定向重下；参考摘要有疑问时保留原件和证据，不无限循环重下。
- 源版本一致、范围正确、分块落盘、断点持久化是恢复基础；文件头尾和边界抽样不能证明全文正确。
- 生信任务的重试和并发应按站点状态调整，记录明确故障类型；加速开启时保持同一获准通道，不静默直连。
- 改换引擎只能用于没有既有断点的新任务，或用户明确选择另存新任务；不能把两个内核的未完成数据混为一份断点。

## 正式替代的验收要求

1. **功能保留清单**：按原版具体版本、各平台 `--version`、CLI 选项与 RPC 方法登记“原版保留 / 客户端已接入 / 未接入 / 不适用”；未完成项不得标为等价替代。
2. **公平配对**：同一机器、源文件版本、磁盘、代理线路和并发条件下交替运行；同时比较默认配置与相同连接数配置。至少重复多个时段，保留分布与失败记录，不挑最快一轮。
3. **性能指标**：完成耗时、有效吞吐量、首个有效进度时间、CPU、内存、磁盘写入量与额外验证耗时分别报告。指标退化须解释和解决，不能只报告峰值网速。
4. **可靠性指标**：注入断流、超时、429/5xx、错误范围、源版本变化、日志损坏、磁盘不足、暂停、强杀与重启。比较最终成功率、错误完成次数、恢复耗时、保留的有效块和重下字节数。测试集错误完成必须为零，但零错误测试不构成全场景绝对保证。
5. **真实数据**：Windows 优先，三端都测 EBI/ENA/NCBI、多 GB、长时及批量任务，并独立核对全文摘要。要区分源不可达、线路异常和下载器故障。
6. **发行门槛**：通过成品包和旧版升级验证；先预览，再根据证据决定是否扩大默认使用范围。未完成对比前，不把当前候选内核宣传为全面更强。
